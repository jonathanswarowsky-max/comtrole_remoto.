## 🎯 Objetivo
Explique em 2 ou 3 linhas qual problema o seu aplicativo resolve ou para que ele
serve.O aplicativo Controle Remoto LEGO NXT resolve a necessidade de controlar um robô LEGO à distância de forma simples e rápida, permitindo enviar comandos de movimentação em tempo real via Bluetooth através de um dispositivo Android.

## ✨ Funcionalidades
- Funcionalidade 1 :Conectividade Bluetooth (busca, pareamento e indicador visual de status de conexão)
- Funcionalidade 2 :Painel de controle direcional (botões para mover para Frente, Trás, Esquerda e Direita)
- Funcionalidade 3 :Botão de Parada de Emergência (Stop instantâneo dos motores)

## ️ Tecnologias Utilizadas
MIT App Inventor (Desenvolvimento e programação em blocos)

Bluetooth (Protocolo de comunicação sem fio com o bloco LEGO NXT)

GitHub (Hospedagem do projeto e código-fonte)

## 📂 Como testar este aplicativo?
Baixe o arquivo .aia disponível neste repositório.

Acesse o MIT App Inventor.

Clique em Projetos > Importar projeto (.aia) do meu computador.

Selecione o arquivo baixado para visualizar e testar o código!
