# comtrole_remoto.
O Controle Remoto é um app Android criado no MIT App Inventor para comandar um robô LEGO Mindstorms NXT via Bluetooth em tempo real. Em tela única, possui seleção de conexão, botões direcionais (frente, trás, esquerda e direita) e parada de emergência. É voltado a alunos, professores e entusiastas de robótica e programação em blocos.
